What is this report?

Each pVACseq neoantigen candidate is classified by NMD sensitivity with the Lindeboom et al. 2019 rules, applied at the position of the PTC (for frameshifts: the first downstream stop codon). The core hypothesis is that TMZ-induced frameshift mutations create PTCs silenced by NMD - NMD inhibition could expose these neoantigens to immune recognition.

NMD Scoring Methods

Lindeboom Rules (Nat Genet 2019)

Applied to frameshift and stop-gained variants, at the PTC position on the candidate's own transcript. For a frameshift the PTC is the first stop codon of the shifted frame. Rules in priority order:

  • Rule 4 - Start-proximal PTC (<150nt): Pioneer round completes before NMD surveillance → INSENSITIVE
  • Rule 1 - Last exon: No downstream EJC to trigger NMD → INSENSITIVE
  • Rule 3 - Long exon (>407nt): EJC too far downstream → INSENSITIVE
  • Rule 2 - 55nt boundary: PTC >55nt upstream of last EJC → SENSITIVE (canonical NMD), otherwise INSENSITIVE

The VEP NMD plugin result is shown for reference only; it is computed at the variant position and does not enter the classification.

⚠ NMD rules only apply to truncating mutations. Missense variants (NOT_APPLICABLE) are not subject to NMD but remain immunogenic neoantigen candidates.

Priority Tiers

  • Tier 1 - NMD-sensitive + IC50 <50 nM: Primary therapeutic targets - NMD inhibition could expose these neoantigens.
  • Tier 2 - NMD-sensitive + IC50 50–500 nM: Moderate binders, potentially relevant after NMD inhibition.
  • Tier 3 - NMD-insensitive + IC50 <500 nM: Already translated - controls for immune response without NMD inhibition.
  • Unclassified: Missense variants or insufficient transcript information.
